浙大招小办 简洁招生问答前端

使用：在校园网或学校 VPN 环境访问 GitHub Pages 网站。
部署：GitHub Pages 从 main 分支根目录构建；所有资源使用相对路径。
后台：现有浙江大学 Dify 公开应用，问答工作流版本 ca7997c0。
本次只调整学测资格问题的检索域；13组离线与5条实际预览通过，发布后GitHub实问已完成。

此仓库仅包含网页、所选 IconPark 图标与已筛选公开资料索引。
没有模型 API Key、Dify 服务 API Key、管理员凭据或内部来电记录。
浏览器通过公开应用的访客接口取得临时访客凭证；最终答复完整返回后显示。
每次打开或刷新页面均为空白。对话与随机访客标识仅保留当前页面内存，同页可以追问、切换、删除和导出；不读取或写入旧浏览器存储。
问题交由学校 Dify 平台处理并产生服务端会话记录；页面刷新、关闭或本页删除不会删除平台记录。
来源索引供查看原文，不能等同每次实际检索节点的执行记录。

图标取自用户提供的 IconPark 素材包，原文件未修改。
图标的上游许可见 IconPark-LICENSE.txt 与 NOTICE.txt。
本说明不将图标许可扩大为其他招生资料的许可声明。
